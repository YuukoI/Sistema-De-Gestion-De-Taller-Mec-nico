🛠️ Sistema de Gestión de Taller Mecánico (Java & Spring Security)
Este proyecto integra mi experiencia en el sector automotriz con el desarrollo de software profesional. Es una solución integral diseñada para digitalizar la operativa de un taller, priorizando la seguridad de la información y la eficiencia en la gestión de servicios.

Lo más destacado del proyecto:

Seguridad y Control de Acceso: Implementé Spring Security para gestionar la autenticación y autorización. El sistema cuenta con un robusto control de acceso basado en roles (RBAC), asegurando que solo el personal autorizado acceda a datos sensibles de clientes y gestión contable.

Lógica de Negocio Real: Módulos de diagnóstico, mantenimiento y stock diseñados bajo procesos reales de concesionarios, optimizando la trazabilidad del vehículo desde el ingreso hasta el egreso.

Persistencia de Datos: Arquitectura de datos sólida utilizando MySQL y JPA/Hibernate para una gestión eficiente de registros complejos.

Tecnologías utilizadas: 🚀 Backend: Java, Spring Boot, Spring Security. 🗄️ Base de Datos: MySQL, Hibernate. 🛠️ Herramientas: Git, Maven, Postman.

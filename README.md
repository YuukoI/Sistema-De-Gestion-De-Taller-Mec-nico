🛠️ Sistema de Gestión para Taller Mecánico (Full Stack Java)
Este proyecto nace de la combinación de mi experiencia en el sector automotriz con el desarrollo de software profesional. Es una solución integral diseñada para digitalizar la operativa de un taller, optimizando la trazabilidad del vehículo y garantizando la seguridad de la información.

🚗 Funcionalidades principales

Gestión Integral: Control total de clientes, vehículos y órdenes de trabajo.

Trazabilidad: Seguimiento preciso del estado de las reparaciones (pendiente, en proceso, finalizado).

Seguridad (RBAC): Implementación de Spring Security para control de acceso basado en roles, protegiendo datos sensibles y gestión contable.

Eficiencia Operativa: Reducción de errores manuales mediante validaciones de datos y manejo de excepciones robusto.

🧱 Tecnologías utilizadas

Backend: Java & Spring Boot (MVC / API REST).

Frontend: HTML5, CSS3 y Bootstrap.

Seguridad: Spring Security.

Persistencia: Spring Data JPA / Hibernate + MySQL.

Documentación & Herramientas: Swagger, Maven, Git, Postman.

🎯 Objetivo del proyecto Aplicar estándares de la industria para crear un diseño escalable y mantenible, utilizando separación de responsabilidades y un modelo de datos pensado para un entorno real de producción.
